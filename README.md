# **Это System Design социальной сети для курса по System Design**


## Функциональные требования

- Личные сообщения и чаты
- Прочитанность сообщений
- Уведомления пользователей о сообщениях
- Статусы пользвателей
- Отправляют только текстовые сообщения


## Нефункциональные требования

- MAU 72 000 000
- Avaibility 99,95 %
- Максимальное кол - во символов в сообщении 1000
- Макс количество пользователей в чате 1000
- Читает 30 раз в день
- Пишет 20 раз в день
- Сообщения храним в течении 5 лет
